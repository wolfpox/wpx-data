# Maintenance rules library

Pre-packaged catalog of item types that ship with the app. Each type carries
suggested questions, photo prompts, maintenance cadences with reasoning, an
educational note, and links to related item types.

## Contents

- [`SCHEMA.md`](./SCHEMA.md) — schema and authoring conventions
- [`WISHLIST.md`](./WISHLIST.md) — items planned next, by category
- `types/` — one JSON file per item type, named `<id>.json`
